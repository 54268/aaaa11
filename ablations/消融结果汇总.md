# Ablation Results Summary

This file keeps only the current paper-ready result summaries. Module ablation uses the supervised-calibrator protocol: MBS-Calib and PCBM each train their own calibrator and select classwise thresholds using validation-known samples plus generated pseudo-unknown samples only. Real test unknown samples are not used for selection.
